ตรวจเครื่องมือให้พร้อม

เปิด Terminal ใน Antigravity (Ctrl+`) หรือ PowerShell แล้วตรวจว่ามี .NET 10 SDK หรือยัง

PowerShell
dotnet --list-sdks

ต้องเห็นบรรทัดที่ขึ้นต้นด้วย 10. เช่น 10.0.100 [C:\Program Files\dotnet\sdk]

  • ถ้าไม่มี ให้ดาวน์โหลด .NET 10 SDK (x64) จากเว็บ Microsoft ระวังอย่าเลือกตัวที่เป็น Runtime เพราะ build ไม่ได้
  • ใน Antigravity ให้ติดตั้ง extension ภาษา C# (C# Dev Kit หรือตัว C# ที่มีใน marketplace) เพื่อให้มี IntelliSense และขีดเส้นใต้ error
ทำไมต้อง .NET 10Civil 3D 2025 และ 2026 ใช้ .NET 8 ส่วน 2027 เปลี่ยนเป็น .NET 10 และไม่มี binary compatibility กับ add-in ของปี 2026 ดังนั้น DLL ทุกตัวต้อง build ใหม่สำหรับ 2027
2

หาไฟล์ SATemplate จากตัวอย่างของ Autodesk

Subassembly แบบ .NET ทุกตัวต้อง inherit คลาส SATemplate แต่คลาสนี้ไม่ได้อยู่ใน DLL ของ Civil 3D มันมาเป็น source code ในโปรเจกต์ตัวอย่าง ซึ่งปกติอยู่ที่

path
C:\Program Files\Autodesk\AutoCAD 2027\C3D\Sample\Civil 3D API\C3DStockSubAssemblies\

ไฟล์ที่ต้องใช้:

  • SATemplate.cs คือคลาสแม่
  • Utilities.cs มีฟังก์ชันช่วยเพิ่ม point, link, shape
  • ไฟล์อื่นที่สองไฟล์นี้เรียกใช้ เช่น CodesSpecific.cs (ขึ้นกับเวอร์ชัน)
ถ้าหาโฟลเดอร์ไม่เจอให้ค้นชื่อไฟล์ SATemplate.cs ในโฟลเดอร์ C:\Program Files\Autodesk\AutoCAD 2027 ทั้งหมด บางเครื่องจะเป็นไฟล์ zip ที่ต้องแตกก่อน

เปิด SATemplate.cs ดูว่าประกาศ namespace ชื่ออะไร (เช่น Subassembly) เพราะต้องใส่ using ตัวนี้ในไฟล์ของคุณ

สร้างโปรเจกต์ Class Library

PowerShell
mkdir C:\Dev\MySA
cd C:\Dev\MySA
dotnet new classlib -n MySA -f net10.0

จะได้โครงสร้างประมาณนี้

โครงสร้างโฟลเดอร์
C:\Dev\MySA\
└─ MySA\
   ├─ MySA.csproj
   ├─ Class1.cs          ← ลบทิ้ง
   ├─ SATemplate.cs      ← copy มาจากขั้นที่ 2
   ├─ Utilities.cs       ← copy มาจากขั้นที่ 2
   ├─ CodesSpecific.cs   ← ถ้ามี
   └─ Levee.cs           ← subassembly ของคุณ

ใน Antigravity ใช้ File → Open Folder แล้วเลือก C:\Dev\MySA

แก้ไฟล์ MySA.csproj

ขั้นนี้สำคัญที่สุด ให้แทนที่เนื้อหาเดิมทั้งหมดด้วยข้อความนี้

MySA.csproj
<Project Sdk="Microsoft.NET.Sdk">

  <ItemGroup>
    <Reference Include="accoremgd">

      <Private>false</Private>

    <Reference Include="acdbmgd">
      <HintPath>$(Acad)\acdbmgd.dll</HintPath>
      <Private>false</Private>
    </Reference>
    <Reference Include="acmgd">
      <HintPath>$(Acad)\acmgd.dll</HintPath>
      <Private>false</Private>
    </Reference>
    <Reference Include="AecBaseMgd">
      <HintPath>$(Acad)\ACA\AecBaseMgd.dll</HintPath>

    </Reference>

    <Copy SourceFiles="$(TargetPath)" DestinationFolder="C:\C3D_Custom\SA\" />

</Project>
net10.0-windows
ต้องเป็น .NET 10 เท่านั้นจึงจะตรงกับ Civil 3D 2027 ส่วน -windows เปิดให้ใช้ API ฝั่ง Windows ได้
x64
Civil 3D เป็นโปรแกรม 64-bit ถ้าเป็น AnyCPU อาจขึ้น warning หรือโหลดผิดพลาด
Private=false
สั่งไม่ให้ copy DLL ของ Autodesk ออกมาไว้ข้าง DLL ของเรา ถ้าลืมใส่ มักเกิด error ตอนโหลด
$(Acad)
path ที่ติดตั้ง Civil 3D ถ้าติดตั้งไว้ที่อื่นให้แก้บรรทัดนี้บรรทัดเดียว
AeccDbMgd
DLL หลักของ Civil 3D มีคลาส CorridorState, ParamDoubleCollection ฯลฯ
เช็กว่าไฟล์อยู่จริงเปิด File Explorer ไปที่ C:\Program Files\Autodesk\AutoCAD 2027\C3D\ แล้วดูว่ามี AeccDbMgd.dll ถ้าชื่อโฟลเดอร์ต่างจากนี้ให้แก้ HintPath ให้ตรง

ตรวจโครงคลาสใน .cs ของคุณ

โครงขั้นต่ำของ subassembly มีหน้าตาประมาณนี้ ให้เทียบกับไฟล์ตัวอย่างจริง เช่น BasicLane.cs ในโฟลเดอร์จากขั้นที่ 2 เพราะชื่อฟังก์ชันใน Utilities อาจต่างกันในแต่ละเวอร์ชัน

Levee.cs (โครง)
using Autodesk.Civil.Runtime;
using Autodesk.Civil.DatabaseServices;
using Subassembly;   // namespace ของ SATemplate.cs (เปิดไฟล์ดูให้ตรง)

namespace MySA
{
    public class Levee : SATemplate
    {
        // พารามิเตอร์ที่จะโชว์ในแท็บ Parameters ของ Civil 3D
        protected override void GetInputParametersImplement(CorridorState corridorState)
        {
            ParamDoubleCollection p = corridorState.ParamsDouble;
            p.Add("CrestWidth", 4.0);
            p.Add("SideSlope", 2.0);
        }

        // วาด point / link / shape ที่นี่
        protected override void DrawImplement(CorridorState corridorState)
        {
            double crest = corridorState.ParamsDouble.Value("CrestWidth");
            // ... ใช้ Utilities.AddPoint / AddLink ตามตัวอย่างใน BasicLane.cs
        }
    }
}

จดชื่อเต็มของคลาสไว้ใช้ในขั้นที่ 7 คือ namespace.ClassName ในตัวอย่างนี้คือ MySA.Levee

6

Build เป็น .dll

  1. สร้างโฟลเดอร์ปลายทาง C:\C3D_Custom\SA\ ไว้ก่อน (target CopyToC3D ใน csproj จะ copy มาไว้ที่นี่)
  2. ปิด Civil 3D ก่อนทุกครั้ง เพราะถ้าเปิดค้างไว้ ไฟล์ DLL จะถูกล็อกและ copy ทับไม่ได้
  3. รันคำสั่ง build
PowerShell
cd C:\Dev\MySA\MySA
dotnet build -c Release

ถ้าขึ้น Build succeeded จะได้ไฟล์สองที่

  • C:\Dev\MySA\MySA\bin\Release\MySA.dll (ต้นฉบับ)
  • C:\C3D_Custom\SA\MySA.dll (ตัวที่ Civil 3D จะใช้)

error ที่พบบ่อยตอน build

  • The type or namespace 'SATemplate' could not be found หมายถึงยังไม่ได้ copy ไฟล์จากขั้นที่ 2 หรือ using namespace ไม่ตรง
  • Autodesk.Civil... could not be found หมายถึง HintPath ใน csproj ผิด
  • ขึ้นว่าหาคลาสบางตัวไม่เจอ (เช่น Codes) ให้ไปหาไฟล์ที่มีคลาสนั้นในโฟลเดอร์ตัวอย่างแล้ว copy มาเพิ่ม
  • The process cannot access the file หมายถึง Civil 3D ยังเปิดอยู่
7

ตั้ง Trusted Location และสร้างเครื่องมือบน Tool Palette

7.1 Trusted Location

  1. เปิด Civil 3D แล้วพิมพ์ OPTIONS
  2. แท็บ Files → ขยาย Trusted Locations → Add → เลือก C:\C3D_Custom\SA
  3. กด OK ถ้าไม่ทำขั้นนี้ จะมีคำเตือนเรื่องความปลอดภัยทุกครั้ง หรือบางเครื่องจะถูกบล็อกไม่ให้โหลด

7.2 สร้างเครื่องมือ (ไม่ต้องใช้ NETLOAD)

  1. กด Ctrl+3 เพื่อเปิด Tool Palettes แล้วคลิกขวาที่แถบชื่อ palette → New Palette ตั้งชื่อ เช่น “My SA”
  2. ไปที่ palette ของ stock subassembly (เช่น Basic) คลิกขวาที่ BasicLane → Copy
  3. กลับไปที่ palette “My SA” คลิกขวาในพื้นที่ว่าง → Paste
  4. คลิกขวาที่เครื่องมือที่เพิ่ง paste → Properties แล้วแก้ค่าในหมวด Subassembly ตามตารางนี้
Name
Levee (ชื่อที่จะโชว์บน palette)
Assembly
C:\C3D_Custom\SA\MySA.dll
Class name
MySA.Levee ต้องตรงกับในโค้ดทุกตัวอักษร รวมถึงตัวพิมพ์เล็ก-ใหญ่
Image
คลิกขวาที่เครื่องมือ → Specify Image เพื่อเปลี่ยนไอคอน (ไม่บังคับ)
Civil 3D โหลด DLL ให้เองตอนวาง subassembly ครั้งแรก Civil 3D จะอ่าน Assembly กับ Class name แล้วโหลด DLL เอง จึงไม่ต้อง NETLOAD
ถ้าต้องการแจกให้ทีมวิธี copy เครื่องมือเดิมเหมาะกับการใช้เองบนเครื่องตัวเอง ถ้าจะติดตั้งให้คนอื่น ควรทำเป็นไฟล์ Tool Catalog (.atc) ดูตัวอย่างได้ในโฟลเดอร์ C:\ProgramData\Autodesk\C3D 2027\ ซึ่งจะมี tag ระบุ DLL และชื่อคลาสคล้ายกับในตารางด้านบน
8

ทดสอบบน Assembly

  1. พิมพ์ CREATEASSEMBLY แล้วคลิกวาง assembly ในแบบ
  2. คลิกเครื่องมือ “Levee” ใน palette แล้วคลิกที่ marker ของ assembly
  3. เลือก subassembly ที่วาง → คลิกขวา → Subassembly Properties → แท็บ Parameters แล้วตรวจว่าเห็น CrestWidth, SideSlope ของเรา
  4. ลองแก้ค่าพารามิเตอร์แล้วดูว่ารูปตัดเปลี่ยนตาม
  5. เมื่อทุกอย่างถูกต้อง ค่อยนำ assembly ไปใช้ใน Corridor
ถ้าพารามิเตอร์ยังเป็นของ BasicLaneให้ลบ subassembly ตัวนั้นแล้ววางใหม่จาก palette ถ้ายังไม่หาย ให้ลบเครื่องมือแล้วทำขั้น 7.2 ใหม่ หรือเปลี่ยนไปใช้วิธีไฟล์ .atc
ดู error จากโค้ดของเราถ้า subassembly ไม่แสดงผลหรือแสดงผิด ให้เปิด Event Viewer ของ Civil 3D (Toolspace → Panorama) เพราะ exception จากโค้ดจะไปแสดงที่นั่น

วงจรแก้โค้ดรอบถัดไป

หลังจากตั้งค่าเสร็จแล้ว รอบต่อไปจะเหลือแค่ 4 ขั้น

ปิด Civil 3D→แก้ .cs→dotnet build -c Release→เปิด Civil 3D ทดสอบ
