## 2. ข้อ 1 Slope (1:x) — ออกแบบ

### 2.1 ชนิดค่าของ parameter

เพิ่ม field `unit` ใน `spec.params[i]` (ไม่มี field = `number` ⇒ spec เก่าเปิดได้เหมือนเดิม) · ตาราง Parameter มีช่อง **ชนิดค่า** แยกจาก double / long

| `unit` | ชื่อในเว็บ | ค่าที่เก็บ / ใช้ในนิพจน์ / C# | แสดง | ข้อความเตือน (เว็บ = C#) |
|---|---|---|---|---|
| `number` | Number | ตามที่พิมพ์ | `2.5` | `N = 0 < 1, ใช้ 1 แทน` (เหมือนเดิม ไม่มีหน่วย) |
| `slope` | Slope (1:x) | **x** (`1.5`) ⇒ C# `double SideSlope = 1.5;` เหมือนไฟล์จริง | `1:1.5` | `SideSlope = 1:0.5 < 1:1, ใช้ 1:1 แทน` |
| `length` | Length (m) | เมตร | `2 m` | `Depth = 0.5 m < 1 m, ใช้ 1 m แทน` |
| `percent` | Percent (%) | ตัวเลขเปอร์เซ็นต์ (`2` = 2%) | `2%` | `Grade = 12% > 10%, ใช้ 10% แทน` |

- **ชนิด Slope**
  - ช่อง default / min / max พิมพ์ได้ทั้ง `1:1.5` และ `1.5` เก็บเป็น 1.5
  - เลือกชนิดนี้แล้ว **ติ๊ก "ต้องมากกว่า 0" ให้เลย** (เอาออกได้) เพราะ x ≤ 0 ใช้ไม่ได้
  - ตารางมีคำใบ้ว่า min = ชันสุดที่ยอม · max = ลาดสุดที่ยอม (x น้อย = ชัน)
- **C#:** ตัว parameter ไม่เปลี่ยน (ยังเป็น `double`) เปลี่ยนแค่ข้อความเตือน เช่น `"SideSlope = 1:" + SideSlope + " < 1:1, ใช้ 1:1 แทน"`
- `displayName` ที่ตั้งให้อัตโนมัติ เช่น `Cut Slope (1:x)` ใช้ต่อไปได้ ไม่ผูกกับ `unit`

### 2.2 ช่อง slope ของเครื่องมือ

**ช่อง slope จริงๆ มี 2 ที่:**
- `slopeLength.slope` (วาดลาด + ความยาว, ปุ่ม 1:1.5 / 1:2 / 1:3 ที่แถบล่าง)
- `slopeToSurface.slope` (Slope to Surface และจุดตัด / ถมของ Daylight Cut/Fill)

**Extend to Surface ไม่มีช่อง slope** — มันต่อตามทิศของเส้นเดิม

**การเก็บค่า: ไม่เปลี่ยน** — ยังเก็บเป็นนิพจน์ดิ่งต่อราบที่มีเครื่องหมาย (`"-1/SideSlope"`)
- evaluator, CodeGenerator และ spec เก่าไม่ต้องแก้ ผลเหมือนเดิมแน่นอน
- C# ออกมาอ่านง่ายอยู่แล้ว: `SlopeToSurface(cs, "P4", surface, P2, -1.0 / FillSlope, F, 50.0, 3.0)`

**ที่เปลี่ยนคือหน้าตาใน Properties** ช่อง slope ของจุดสองชนิดนี้กลายเป็น `[↗ ขึ้น][↘ ลง]` + ช่องข้อความ

| พิมพ์ในช่อง | เก็บเป็น (↘ ลง) | หมายเหตุ |
|---|---|---|
| `1:1.5` | `-1/1.5` | |
| `SideSlope` (parameter ชนิด Slope) | `-1/SideSlope` | |
| `2%` | `-2/100` | |
| `Grade` (parameter ชนิด Percent) | `-Grade/100` | |
| `-0.667` หรือนิพจน์อื่น | ตามที่พิมพ์ | เป็นโหมด "นิพจน์ดิ่งต่อราบ" — ↗ / ↘ ปิดไว้ เพราะเครื่องหมายอยู่ในนิพจน์แล้ว (แบบเดิม) |

**เปิด spec เก่า:** เว็บอ่านนิพจน์เดิมกลับมาแสดงเป็นแบบอ่านง่ายเมื่อเข้ารูปแบบ `±1/ชื่อ`, `±1/ตัวเลข`, `±ชื่อ/100`, `±ตัวเลข/100`
- นอกนั้นแสดงเป็นนิพจน์ตามเดิม
- **ไม่เขียนทับค่าเดิมจนกว่าผู้ใช้จะแก้ช่องนั้น**

**จุดอื่นที่แก้ด้วย**
- ปุ่ม **Slope to Surface:** banner / ช่องพิมพ์รับ `SideSlope` และ `1:x` แบบเดียวกัน
- หน้าต่าง **Daylight Cut/Fill**
  - ช่องลาดตัด / ถมรับชื่อ parameter ชนิด Slope ที่มีอยู่แล้ว (มีรายการให้เลือก) แทนการสร้าง `CutSlope` / `FillSlope` ใหม่
  - ถ้าให้สร้าง `CutSlope` / `FillSlope` ใหม่ จะได้ `unit: slope`

  - อ่าน / เขียนช่อง slope ทั้ง 4 แบบ

## 4. ข้อ 5 (จุดล่างในของดินใน body ด้วย Extend to Surface) — ทำได้เลย ไม่ต้องแก้โค้ด

**Extend to Surface รองรับเส้นดิ่งอยู่แล้ว** ทั้ง JS และ C#: `dx = 0`, `dy < 0` ⇒ ชนดินที่ x เดิม

**วิธีทำ (กดในเว็บ)**
1. วาด link aux `P1 → S0` (S0 = จุดตัดเส้นดินกับเส้นดิ่งที่ origin)
2. Extend to Surface ที่ปลาย S0 ได้ "ปลายจริง" = firstOf[จุดต่อ, S0]
3. ใน Properties เอา Auxiliary ของปลายจริงออก + ใส่ code `SoilBaseInside`

ทำแบบเดียวกับที่ M6 ทำ `SoilToe` — firstOf ที่ไม่ใช่ aux ⇒ `AddPoint` ที่ตำแหน่งจุดแรกที่เกิด จึงไม่มีจุดเกินใน Civil 3D

**ทำไมได้ผลเท่ากับ `min(ground(P1), S0.y)`**
- ดินต่ำกว่า S0 = ปลายลอย ⇒ ต่อลงถึงดิน
- ดินสูงกว่าหรือเท่ากับ S0 = ไม่ต่อ ⇒ ใช้ S0

ลองในเบราว์เซอร์แล้ว: ดินสูง / ต่ำ / ขรุขระ / ไม่มีดิน × Height 2, 5, 9 × Right / Left (24 กรณี) **ตำแหน่งตรงกับ `min()` ทุกกรณี**

**ต่างกันข้อเดียว:** ไม่มี Target Surface แล้ว `min()` เตือน "ground(P1): ไม่ได้กำหนด Target Surface" แต่ Extend เงียบ (ผลเท่ากัน)
