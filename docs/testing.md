# Testing

Run everything quietly with `test-all.bat` (repository root): one summary line per suite plus only the failures; full log in `SA.Tests/test-all.log`. Close the viewer first: a running viewer locks the build output.

Tests must never read the user's working files at the root (`*.cs`, `*.assembly.json`). Use the locked copies in `SA.Tests/fixtures/` (frozen from commit e1fa131).

End-to-end (not in `test-all.bat`; needs a viewer with a page open and the copies from `SA.Tests/fixtures/round6/` imported): `node SA.Tests/e2e/mcp-e2e.js http://localhost:5050/mcp`.

UI smoke test of the round 9 shell (not in `test-all.bat`; needs a running **test** server — scratch `SA_STUDIO_MACHINE_DIR`, copies only): `node SA.Tests/e2e/ui-smoke.js http://localhost:5051/`. Playwright is not installed, so it drives the installed Chrome / Edge headless through the DevTools protocol (no packages, own temporary profile): page loads, each ribbon tab switches, Home › Edit shows Draw / Modify / Logic and Finish returns, a palette closes and Reset layout restores it, `?` opens the table, no script errors. No browser found = "skipped".

Manual checklist for the shell (round 9, no Civil 3D needed): open a project → click every ribbon tab (tooltips show name, key, Thai line, why off) → Edit a subassembly from the tree / right-click / Home › Edit (Draw tab opens) → draw a point, link, shape, Slope to Surface with the ribbon only → Modify › Move / Rotate → Logic › Conditions → Finish › Save (.cs) → ออกจาก Edit (previous tab returns) → View › Scenario dropdown → Output › Build → AI palette → drag / tab / Shift-float / close palettes, refresh (layout kept), View › Palettes › Reset layout → double-click a tab (ribbon minimises) → narrow the window (panels scroll sideways) → `?` table.
