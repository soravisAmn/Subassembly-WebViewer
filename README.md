# SA Drawing Studio (Subassembly Viewer)

เว็บสำหรับดูรูปร่าง subassembly จากไฟล์ .cs ตัวจริง (ไฟล์เดียวกับที่ build ลง Civil 3D)
โดยไม่ต้องเปิด Civil 3D: วางไฟล์ .cs แล้วเว็บจะคอมไพล์ รัน และวาดให้ทันที
แก้โค้ดแล้วกด Save เว็บจะวาดใหม่เองภายใน 1–2 วินาที

และ **วาด** subassembly แบบ CAD แล้วสร้างไฟล์ .cs ให้อัตโนมัติ (รอบแรก: `prompt.md` ถึง Milestone 3 — วาดแล้วกด **Save (.cs)** ได้ไฟล์ที่ build ลง Civil 3D ได้)

**รอบ 2 (`prompt-2.md`)** — ทำงานแบบ AutoCAD ให้มากที่สุด:

| เรื่อง | สรุป | หัวข้อ |
|---|---|---|
| Snap | OSNAP (`F3`) + ชนิดแยก, Grid snap (`F9`), เลือกตัวใกล้สุด, `Tab` วน snap, marker แบบ AutoCAD | **วาด** |
| เลือก | Window / Crossing, `Shift` เอาออก, `Ctrl+A`, `Esc` · pan ด้วยปุ่มกลางเมาส์ / `Space` + ลาก | **เลือก** |
| Undo / Delete | `Ctrl+Z / Y` ครอบทุกการกระทำ · `Delete` หลายชิ้นพร้อมถามเมื่อมีของพึ่งอยู่ | **Undo / Redo และ Delete** |
| Move / Copy / Paste | `M`, `C`, `Ctrl+C / X / V` มีเงา + snap · ย้ายแบบไม่ทำความหมายของจุดพัง · ใช้กับ subassembly ทั้งตัวได้ | **Move / Copy / Paste** |
| object → โค้ด | เลือก object แล้วเห็นบรรทัดในไฟล์ + ปุ่มไปที่โค้ด, เคอร์เซอร์ในโค้ด → เน้น object | **object → บรรทัดโค้ด** |
| Shortcut | กด `?` / `F1` บนหน้าเว็บ | **Shortcut** |

ที่ต่างจาก AutoCAD (และเหตุผล) รวมไว้ที่หัวข้อ **ต่างจาก AutoCAD** ท้ายไฟล์

## หน้าจอ

| ส่วน | อยู่ที่ | มีอะไร |
|---|---|---|
| เมนูบาร์ | บนสุด | **ไฟล์ ▾** (Import .cs, สร้าง .cs ใหม่, Open / Save project, Export scenarios), **✎ แก้โค้ด** |
| ต้นไม้ Workspace | ซ้าย | Workspace → Surface / Assembly → Subassembly → Points / Links / Shapes / Parameters · Scenarios |
| Workspace | กลาง | รูปตัด (พื้นมืดแบบ CAD) + แถบผลลัพธ์ด้านล่าง (Messages / Log / Points ของตัวที่เลือก) |
| Drawer + Properties | ขวา | เครื่องมือวาด (ใช้ได้ใน Edit mode) · ค่าของสิ่งที่เลือก (parameter, ค่าของจุดที่วาด แก้ได้ที่นี่) |
| แถบล่าง | ล่างสุด | พิกัดเมาส์, Grid, Grid snap (F9), Ortho (F8), slope สำเร็จรูป, OSNAP (F3) + ชนิด, point codes, VE, Fit, สถานะ server |

- **คลิก** ในต้นไม้หรือบนรูป = เลือก (จุด / link / shape ที่เลือกเน้นสีส้มบนรูป และค่าขึ้นใน Properties) — เลือกหลายชิ้น ดูหัวข้อ **เลือก (Window / Crossing)**
- **pan** = ลากด้วยปุ่มกลางเมาส์ (แบบ AutoCAD) หรือกด `Space` ค้างแล้วลากปุ่มซ้าย (touchpad) · ล้อเมาส์ = zoom
- **คลิกขวา** ที่ subassembly (ในต้นไม้หรือบนรูป): Edit, ✎ แก้โค้ด, Rename, Save เป็น .cs, Move, Copy, Mirror, เอาออกจาก assembly
  ("รูปทรงของฉัน" มาในระยะสอง) · คลิกขวาที่ point / link / shape ที่วาด: Move, Copy, ลบ
- **คลิกขวา** ที่ assembly (หรือแกน ⊞ บนรูป): **ADD** (subassembly ใหม่ แล้วเข้า Edit), Import .cs เข้า assembly นี้, Rename, ลบ assembly
- **คลิกขวา** ที่ Workspace / พื้นว่าง: + Assembly ใหม่, Import .cs, Fit
- **Edit mode**: แถบน้ำเงินด้านบน "กำลังแก้ X" ตัวอื่นจางและคลิก/ลากไม่ได้ · กด **ออกจาก Edit** เพื่อกลับ (ดูหัวข้อ **วาด**)
  ปุ่ม **Save (.cs)** (หรือ Ctrl+S) เขียนส่วนที่วาดลงไฟล์ (ดูหัวข้อ **Save (.cs) และโค้ดที่สร้าง**)
- Ortho, slope สำเร็จรูป (คลิก = ล็อก, ดับเบิลคลิก = แก้ค่า) และ OSNAP ใช้ตอนวาด
- ค่าที่ตั้งไว้ทั้งหมด (workspace, ต้นไม้ที่กางไว้, แถบล่าง) จำไว้ในเบราว์เซอร์ รีเฟรชแล้วยังอยู่
  ครั้งแรกหลังอัปเดต เว็บย้ายของเดิมมาให้เอง: assembly เดิม → Assembly 1, ไฟล์ที่เปิดในโหมดไฟล์เดียว → subassembly ตัวเดียวเกาะแกน

## วาด (Edit mode)

คลิกขวาที่ subassembly → **Edit** (หรือคลิกขวาที่ assembly → **ADD** = subassembly ใหม่ว่างๆ มีจุด P1 ที่ origin ให้แล้ว)

| เครื่องมือ (Drawer) | คีย์ | ใช้ยังไง |
|---|---|---|
| Point | `P` | คลิกวางจุด (อ้างจากจุดที่เลือกอยู่ ถ้าไม่ได้เลือก = จาก origin) |
| Link | `L` | คลิกต่อไปเรื่อยๆ = polyline · จุดปลายเกิดเอง · คลิกชนจุดเดิม = ใช้จุดเดิม · คลิกขวา / `Enter` = จบเส้น |
| Shape | `S` | คลิกจุดรอบรูปตามลำดับ แล้วคลิกจุดแรก (หรือ `Enter`) = ปิดรูป · ขาด link ตรงไหนสร้างให้เอง |
| ลาดจนชนดิน | | คลิกจุดเริ่ม แล้วเลื่อนเมาส์เลือกทิศ คลิก = จุด daylight (slope ตามปุ่มที่ล็อกในแถบล่าง ไม่ล็อก = 1:2) |
| วิ่งตามผิวดิน | | คลิกจุดเริ่ม แล้วคลิกจุดปลาย = link ที่วิ่งตามผิวดิน (ได้จุดหักของดินระหว่างทาง) |
| ขอบเขตค่า | | เปิดตาราง Parameter |

- ระหว่างลาก tooltip บอก slope (1:x และ %), ความยาว, dx / dy และชนิด snap
- **พิมพ์ค่าแทนการคลิก** (แบบ Dynamic Input): พิมพ์ตัวเลข / `-` / `.` ได้เลย หรือกด **`Tab`** (เมื่อไม่มี snap ให้วนเลือก)
  ช่อง dx, dy, slope (พิมพ์ `1:2` ได้ ขึ้น/ลงตามเมาส์), ยาว — ช่องที่เว้นว่างใช้ค่าจากเมาส์ · พิมพ์ชื่อ parameter / นิพจน์ได้ (ผิด = ขึ้นแดง)
- **Ortho** (`F8`) ล็อกแนวราบ/ดิ่ง · **slope สำเร็จรูป** ล็อกมุม · **Grid snap** (`F9`) ปัด dx / dy / ระยะตามลาดของจุดอิสระ ทีละ 0.05 m
  (ดับเบิลคลิกปุ่มเพื่อตั้งระยะ) — ใช้ตอนลากจุด surface / แกน / subassembly ที่ลอยอยู่ด้วย · **ไม่ใช่ object snap**
- **OSNAP** (`F3` = เปิด/ปิดทั้งหมด แบบ AutoCAD) + ปุ่มแยกชนิด · ทุกเครื่องมือวาดใช้ปุ่มชุดเดียวกัน · กดปุ่มแล้วเห็นผลทันทีโดยไม่ต้องขยับเมาส์

  | marker | ชนิด | จับที่ |
  |---|---|---|
  | □ สี่เหลี่ยม | Endpoint | จุดที่วาด / จุดของโค้ดเดิม / origin |
  | △ สามเหลี่ยม | Midpoint | กึ่งกลาง link |
  | ✕ กากบาท | Intersection | จุดตัดของ 2 link (ที่ไม่ได้ต่อกันที่ปลาย) |
  | ⊠ สี่เหลี่ยมมีกากบาท | ลาดชนดิน | ล็อก slope + เปิด Surface: จุดที่ลาดจากจุดก่อนหน้าชนดิน (จับได้ไกลกว่า 2.5 เท่า) |
  | ⊥ มุมฉาก | Perpendicular | ตั้งฉากจากจุดก่อนหน้าไปยัง link |
  | ⧗ นาฬิกาทราย | Nearest | จุดบน link ที่ใกล้เมาส์ |
  | เส้นดินมีขีด | Surface | จุดบนผิวดินที่ใกล้เมาส์ |

  - เลือก snap ที่ **ใกล้เมาส์ที่สุด** ในรัศมี 12 px · ระยะเท่ากัน = Endpoint ชนะ
  - Nearest และ Surface เป็นตัวสำรอง ใช้เมื่อไม่มี snap ชนิดอื่นในรัศมี (แบบ Nearest ของ AutoCAD — ไม่งั้นจะชนะทุกครั้งเพราะอยู่ใต้เมาส์พอดี)
  - มีหลายตัวในรัศมี (ป้ายขึ้น `(1/3)`) → **`Tab` = วนไปตัวถัดไป** แบบ AutoCAD · ขยับเมาส์จนรายการเปลี่ยน = เริ่มที่ตัวใกล้สุดใหม่
  - ปิด Endpoint / ปิด OSNAP แล้วคลิกบนจุดเดิม = ได้ **จุดใหม่** ซ้อนที่เดิม (แบบ AutoCAD) ไม่ใช่ใช้จุดเดิม
  - ตอนเลือกจุดฐาน / ปลายทางของ Move / Copy / Paste ใช้ snap ชุดนี้ด้วย · จุดที่วาดแล้วยังลากด้วยเมาส์ตรงๆ ไม่ได้ (ใช้ `M`)
  - logic เลือก snap อยู่ใน `js/snap.js` (ไม่แตะหน้าจอ) ทดสอบด้วย `node SA.Tests/js/snap.test.js`
- `Ctrl+Z` / `Ctrl+Y` = Undo / Redo (ดูหัวข้อ **Undo / Redo และ Delete**) · `Delete` = ลบสิ่งที่เลือก · `Esc` = ยกเลิกเส้น / ออกจากเครื่องมือ
- ปุ่มกลางเมาส์ลาก หรือ `Space` + ลาก = pan (ใช้ได้ระหว่างวาด) · ล้อเมาส์ = zoom

**ทุกอย่างที่วาดเก็บเป็น "ความหมาย"** ไม่ใช่แค่พิกัด เช่น จุดที่วาดด้วย slope 1:2 จาก P2 เก็บเป็น `ลาด -1/2 จาก P2 ยาว 2.236`
เปลี่ยน parameter หรือเส้น surface แล้วรูปเปลี่ยนตามทันที · ดู/แก้ความหมายได้ใน Properties ของจุดนั้น:

| ชนิดจุด | ความหมาย |
|---|---|
| Origin | จุด origin (0, 0) |
| ห่างจากจุด (dx, dy) | dx ไปทางนอก (+), dy ขึ้น (+) จากจุดที่เลือก |
| ลาด + ความยาว | slope = dy/dx (ลง = ลบ) ไปทางนอก/ใน ยาวตามแนวลาด / ระยะราบ / ระยะดิ่ง |
| ลาดจนชนดิน | ลาดจนชน Target Surface · ไม่ชนภายในระยะที่กำหนด = หยุด + เตือน · Layout / ไม่มีดิน = ยาวคงที่ |
| บนผิวดิน | ระดับผิวดินที่ระยะ dx จากจุดที่เลือก |
| บนเส้นระหว่าง 2 จุด | สัดส่วน t (0.5 = กึ่งกลาง) |
| จุดตัดของ 2 เส้น | จุดตัดของเส้น a1-a2 กับ b1-b2 |
| จุดจากโค้ดเดิม | จุดของโค้ดในไฟล์ หาด้วย point code (ไม่เจอ = เตือน แล้วข้ามสิ่งที่พึ่งจุดนี้) |

- **ทุกช่องตัวเลขรับนิพจน์**: ตัวเลข, ชื่อ parameter, `+ - * / ( )`, `min max abs sqrt pow`, `sin cos tan` (องศา), `atan` (ได้องศา) — ตรวจตอนพิมพ์ ชื่อผิด/วงเล็บไม่ครบ = ขึ้นแดง
- **ตาราง Parameter แบบ SAC** (Properties ของ subassembly หรือโหนด Parameters): ชื่อ, ชนิด, default, display name, min / max
  ค่าที่ต่ำกว่า min / สูงกว่า max ใช้ค่าขอบแทน แล้วขึ้นเตือนใน Messages (แบบที่โค้ดเดิมทำกับ Depth < 2 m)
  เปลี่ยนชื่อ parameter แล้วนิพจน์ที่ใช้ชื่อนั้นเปลี่ยนตามให้เอง · ไฟล์ที่ import ใช้ parameter ของไฟล์เดิมในนิพจน์ได้เลย
- `Side` = 1 (Left) กลับด้านแนวราบของส่วนที่วาดทั้งหมด · Mirror ใช้ได้กับตัวที่วาดด้วย
- ส่วนที่วาดเก็บใน project (Save project) และในเบราว์เซอร์ · เขียนลงไฟล์ .cs เมื่อกด Save (.cs) เท่านั้น
- subassembly ตัวอื่นเกาะจุดที่วาดได้ (ใช้ผลรันโค้ด C# ที่สร้าง) · ไฟล์ที่เขียนเองแล้ววาดเพิ่ม ยังเกาะจุดที่วาดเพิ่มไม่ได้ และ Save ลงไฟล์ที่ยังไม่มีช่วง SA-DRAWING ไม่ได้ (รอบแรก Milestone 4 ยังไม่ได้ทำ)

## เลือก (Window / Crossing)

แบบ AutoCAD (ตั้งค่าแบบ PICKADD = เพิ่มเข้าชุด):

| ทำอะไร | ผล |
|---|---|
| ลากพื้นหลัง **ซ้าย → ขวา** | **Window** (กรอบเส้นทึบสีฟ้า): เลือกเฉพาะ object ที่อยู่ในกรอบทั้งตัว |
| ลากพื้นหลัง **ขวา → ซ้าย** | **Crossing** (กรอบเส้นประสีเขียว): เลือก object ที่แตะกรอบ |
| คลิก object / คลุมอีกครั้ง | **เพิ่ม** เข้าชุดที่เลือกอยู่ |
| `Shift` + คลิก / คลุม | **เอาออก** จากชุด |
| `Ctrl` + คลิกในต้นไม้ | เพิ่ม / เอาออก (คลิกธรรมดาในต้นไม้ = เลือกชิ้นเดียว) |
| `Ctrl+A` | เลือกทั้งหมด |
| `Esc` / คลิกที่ว่าง | ยกเลิกการเลือก |

- **Edit mode**: เลือก point / link / shape ที่วาดของตัวที่แก้เท่านั้น (เริ่มลากบน object ก็เป็นการคลุมเลือก ไม่ได้ลาก object)
  จุด / link ของโค้ดเดิมยังคลิกดูค่าได้ทีละชิ้น แต่ไม่รวมเข้าชุด · เครื่องมือ Point อ้างจากจุดที่เลือกล่าสุด
- **นอก Edit mode**: เลือก subassembly ทั้งตัว · ลาก subassembly = ย้าย/เกาะเหมือนเดิม
  คลิกซ้ำที่ตัวที่เลือกอยู่ตัวเดียว = เลือกจุด / link / shape ข้างใน (ดูค่าใน Properties)
- ที่เลือกเน้นทั้งบนรูปและในต้นไม้ · Properties แสดง "เลือก N objects" แยกตามชนิด, รายการ (คลิก = เลือกเฉพาะชิ้นนั้น, × = เอาออก)
  และช่อง **Codes** แก้ทุกชิ้นพร้อมกัน (Edit mode · Ctrl+Z ย้อนได้ทีเดียว) · ปุ่ม Move / Copy / Delete ใช้ได้
- **ต่างจาก AutoCAD**: AutoCAD คลิกที่ว่าง = เริ่มกรอบ (คลิก 2 ครั้ง) และลากค้าง = lasso — ที่นี่ใช้ **ลากค้าง = กรอบ** อย่างเดียว
  และคลิกที่ว่าง = ยกเลิกการเลือก เพราะการลากเป็นวิธีที่คนใช้เมาส์ในเว็บคุ้น และไม่ต้องมีโหมดค้างระหว่างคลิก 2 ครั้ง
- logic ของกรอบอยู่ใน `js/select.js` (ไม่แตะหน้าจอ) ทดสอบด้วย `node SA.Tests/js/select.test.js`

## Move / Copy / Paste

แบบ AutoCAD — ใช้ได้ทั้ง **Edit mode** (point / link / shape ที่วาด) และ **นอก Edit mode** (subassembly ทั้งตัว)

1. เลือกก่อนแล้วกด **`M`** (Move) / **`C`** (Copy) — หรือกดก่อนแล้วค่อยเลือก (คลิก / คลุม) แล้ว **Enter** (หรือคลิกขวา)
   (ปุ่ม Move / Copy ใน Properties ตอนเลือกหลายชิ้น และในเมนูคลิกขวา ก็ได้)
2. คลิก **จุดฐาน** (base point) → เห็น **เงา** (เส้นประสีเขียว) ตามเมาส์ → คลิก **ปลายทาง**
   - ใช้ **OSNAP** (Tab วน snap ได้), **Grid snap**, **Ortho** (F8), **ล็อก slope** ได้เหมือนตอนวาด
   - **พิมพ์ระยะ**: พิมพ์ตัวเลขเลย หรือ **Tab** (เมื่อไม่มี snap ให้วน) → dx, dy (บนจอ: ขวา +, ขึ้น +) หรือ slope (`1:2`) + ยาวตามแนวลาด · ช่องว่าง = ใช้ค่าจากเมาส์
   - **Copy** วางซ้ำได้เรื่อยๆ จน **Enter** / **Esc** · **Esc** = ยกเลิกคำสั่ง · ทุกครั้งที่วาง = Undo 1 ก้อน
3. **`Ctrl+C`** / **`Ctrl+X`** = คัดลอก / ตัดที่เลือก · **`Ctrl+V`** = วาง (เงาตามเมาส์ทันที จุดฐาน = มุมซ้ายล่างของชุดที่คัดลอก) — ในช่องพิมพ์ / แถบโค้ด = copy ข้อความปกติ

**ย้ายแบบไม่ทำความหมายพัง (Edit mode)** — spec เก็บ "ความหมาย" ของจุด:

| จุดในชุดที่เลือก | ผลตอนย้าย |
|---|---|
| ห่างจากจุด (dx, dy) ที่อ้างจุดนอกชุด / origin = **ราก** | แก้ dx / dy — นิพจน์ที่อ้าง parameter **เขียนต่อท้าย** เช่น `Width` → `Width + 1.25` (ย้ายซ้ำรวมค่าคงที่ให้: `Width + 0.5`) |
| อ้างตามจุดที่ย้ายอยู่แล้ว (dx,dy / ลาด จากจุดในชุด, บนเส้น / จุดตัดที่ปลายย้ายหมด) | ตามไปเอง ไม่ต้องแก้ |
| ลาด + ความยาว ที่เป็นราก | แปลงเป็นระยะ dx, dy ที่ตำแหน่งใหม่ (เส้นลาดเดิมไม่ผ่านตำแหน่งใหม่แล้ว) |
| ลาดจนชนดิน, บนผิวดิน, บนเส้น / จุดตัดของจุดที่ไม่ได้ย้าย, จุดของโค้ดเดิม, origin | **ไม่ย้าย** — แถบบอกด้านบนบอกว่าจุดไหนเพราะอะไร + ปุ่ม **แปลงเป็นระยะคงที่ (delta) แล้วย้าย** (origin ย้ายไม่ได้) |

- จุด**นอก**ชุดที่อ้างจุดที่ย้าย ขยับตามด้วย (เห็นในเงา และ tooltip บอก "ขยับตาม …") — ต่างจาก AutoCAD ที่ย้ายแค่ที่เลือก แต่แบบนี้รูปไม่ขาด
- **Copy**: สำเนาได้ id ใหม่ · ความสัมพันธ์ในชุดอ้างกันเอง ส่วนที่อ้างจุดนอกชุดยังอ้างตัวเดิม · code ติดไปด้วย (ซ้ำได้แบบ Civil 3D — ต้นไม้ขึ้น "code ซ้ำ")
- **Paste ข้าม subassembly** (Ctrl+C ในตัวหนึ่ง → เข้า Edit อีกตัว → Ctrl+V): จุดที่อ้างของนอกชุด / origin / จุดของโค้ดเดิม / นิพจน์ที่ใช้ parameter ที่ตัวใหม่ไม่มี
  แปลงเป็นระยะคงที่จาก origin ของตัวใหม่ · ส่วนวาดวางได้เฉพาะใน Edit mode, subassembly วางได้นอก Edit mode
- **นอก Edit mode**: Move = ย้ายจุดเกาะแบบเดียวกับการลาก (origin ตกใกล้แกน / จุดของตัวอื่น = เกาะ ไม่งั้นลอย) · ตัวที่เกาะกับตัวที่ย้ายตามไปเอง
  · Copy / Paste = สำเนา (ไฟล์ .cs เดียวกัน parameter เดียวกัน; ตัวที่ยังไม่มีไฟล์ได้ชื่อไฟล์ `-copy.cs`)
- logic อยู่ใน `js/ops.js` (ไม่แตะหน้าจอ) ทดสอบด้วย `node SA.Tests/js/ops.test.js`

## object → บรรทัดโค้ด

เลือก point / link / shape (ทั้งที่วาดในเว็บ และที่มาจากโค้ดที่เขียนเอง) → Properties มีกลุ่ม **โค้ด**:

- ส่วนที่วาด: `pavement-assembly.cs บรรทัด 111, 138` — จุด = บรรทัดคำนวณพิกัด (`Pt? P3 = …`) + บรรทัดเพิ่มลง CorridorState (`AddPoint(cs, P3)`), link / shape = บรรทัด `AddLink` / `AddShape`
- โค้ดที่เขียนเอง: ทั้งสายที่เรียก เช่น `บรรทัด 360 (AddShape) ← เรียกจาก 221 (DrawImplement) ← เรียกจาก 130 (Draw)` — กดได้ทุกเลข
- ปุ่ม **ไปที่โค้ด** = เปิดแถบโค้ดที่บรรทัดนั้นและเน้นบรรทัด (สีม่วง) · ตอนแถบโค้ดเปิดอยู่ เลือก object อื่นแล้วเน้นตามเอง
  (ถ้าโหลด Monaco ไม่ได้ แถบโค้ดสำรองเลื่อนไปบรรทัดอย่างเดียว ไม่เน้น)
- **ทางกลับ**: คลิก / เลื่อนเคอร์เซอร์ในแถบโค้ดไปบรรทัดที่สร้าง object → object นั้นเน้นบนรูป (สีม่วง)
  บรรทัดในฟังก์ชันช่วยที่สร้างหลาย object (เช่น `points.Add` ใน loop) = เน้นทุกตัวที่บรรทัดนี้สร้าง
- เลขบรรทัดอ้างโค้ดที่รันจริง: ไฟล์บนดิสก์ / โค้ดในแถบแก้ (ที่ยังไม่บันทึกก็ตรง) / โค้ดที่สร้างจากการวาด (ตัวที่ยังไม่มีไฟล์)
  ส่วนที่วาดในไฟล์ที่มีอยู่แต่ยังไม่ได้ Save = เลขบรรทัดของโค้ดหลัง Save → ปุ่มเป็น **Save (.cs) แล้วไปที่โค้ด**
- วิธีหา: ส่วนที่วาด = server อ่านจากช่วง `SA-DRAWING` ของโค้ดที่รัน (`CodeGenerator.SourceMap`) จึงตรงทั้งไฟล์ใหม่และไฟล์ที่ช่วงนี้อยู่กลางไฟล์
  · โค้ดที่เขียนเอง = ตัวจำลองจำ "ใครเรียก" `Points.Add` / `Links.Add` / `Shapes.Add` ด้วย StackTrace + PDB (`SA.Civil3DShim/CallSites.cs`)
  เลขบรรทัดตรงกับไฟล์จริงแม้เว็บแทรกจุดตรวจของ RunGuard (ยืนยันด้วย test ที่มี loop / ฟังก์ชันช่วย / local function)
- ความเร็ว: เก็บบรรทัดเพิ่มประมาณ 37 µs ต่อจุด (1000 จุด ≈ 37 ms ต่อการรัน · `base_rock-pitching.cs` รันทั้งหมด 9 ms) จึงเปิดไว้ตลอด
  (ปิดได้ด้วย `"sites": false` ใน /api/assembly ถ้าไฟล์มีจุดเป็นหมื่น)

## Undo / Redo และ Delete

- **`Ctrl+Z`** = Undo · **`Ctrl+Y`** หรือ **`Ctrl+Shift+Z`** = Redo — ใช้ได้ทุกที่ (ทั้งใน Edit mode และนอก Edit mode) ย้อนได้ 200 ครั้ง
- ครอบคลุมทุกการกระทำที่เปลี่ยนงาน: วาด, ลบ, แก้ค่าใน Properties (ค่าของจุด, codes, parameter, ตาราง parameter, Datum, Corridor/Layout),
  ลาก / เพิ่ม / ลบจุด surface, เลื่อนทั้งเส้น surface, ย้าย / เกาะ / Mirror / เพิ่ม / ลบ subassembly, ย้ายแกน assembly, เพิ่ม/ลบ assembly, โหลด scenario / project
- **1 การกระทำ = 1 ก้อน**: ลากต่อเนื่อง = ก้อนเดียว (นับตอนปล่อยเมาส์) · พิมพ์ในช่องของ Properties = ก้อนเดียวต่อช่อง (นับตอนออกจากช่อง) · ลบหลายชิ้น = ก้อนเดียว
- แถบบอกด้านบนแสดงว่าย้อนอะไรไป เช่น `Undo: ย้ายแกน Assembly 1`, `Undo: แก้ dx · pavement-assembly.cs · P6`, `Undo: ลบ 3 objects`
- **ไม่ย้อน**: การ Save ไฟล์ .cs / project (ไฟล์ที่เขียนลงดิสก์แล้วไม่ถูกเปลี่ยนกลับ — undo แล้ว Save ใหม่ถ้าต้องการ), มุมมอง (zoom/pan),
  ที่เลือก, ปุ่มในแถบล่าง และการเข้า/ออก Edit · Undo หายเมื่อรีเฟรชหน้าเว็บ
- ตอนพิมพ์อยู่ในช่องพิมพ์ / แถบโค้ด `Ctrl+Z` = undo ของช่องนั้นเอง (แบบเดิม)
- **`Delete`** (หรือปุ่ม Delete ใน Properties): Edit mode = ลบ point / link / shape ที่เลือก · นอก Edit = เอา subassembly ที่เลือกออก (ตัวที่เกาะอยู่กับมันจะลอยอยู่ที่เดิม)
  · จุด surface ที่เลือก = ลบจุดนั้น — ถ้าของที่จะลบมีสิ่งอื่นพึ่งอยู่ (link / shape / จุดที่อ้างถึง) จะบอกรายการที่จะหายไปด้วยแล้วให้ยืนยันก่อน

## Save (.cs) และโค้ดที่สร้าง

- ทุกครั้งที่วาด/แก้ เว็บสร้างโค้ด C# แล้ว **คอมไพล์ + รันกับตัวจำลองในหน่วยความจำ** (preview ด้วย Roslyn) แต่ **เขียนลงไฟล์เมื่อกด Save (.cs) เท่านั้น**
  - รูปที่เห็นมาจากตัวคำนวณในเบราว์เซอร์ (เร็ว) แล้วเว็บเทียบกับผลรันโค้ด C# ให้เอง — ไม่ตรงกัน = ขึ้นกรอบแดงใน Messages
  - Properties ของ subassembly บอกสถานะ "ผลรันโค้ด C# ตรงกับรูป" · ในต้นไม้ ● = ส่วนที่วาดยังไม่ได้ Save
- **Save (.cs)** (แถบน้ำเงินตอน Edit, Properties, คลิกขวา หรือ Ctrl+S ตอนอยู่ใน Edit):
  - ตัวที่ ADD ในเว็บ → สร้างไฟล์ใหม่ในโฟลเดอร์ (ชื่อที่กรอกตอน ADD) ถ้ามีไฟล์ชื่อนี้อยู่แล้วที่ไม่ได้สร้างจากเว็บ จะถามก่อนว่าเขียนทับหรือตั้งชื่อใหม่
  - ไฟล์ที่สร้างจากเว็บแล้ว → แทนที่เฉพาะช่วงที่มีป้าย `SA-DRAWING` ส่วนอื่นของไฟล์ (ที่แก้เองได้) ไม่เปลี่ยนแม้แต่ไบต์เดียว · Save ซ้ำได้ผลเดิม
  - ถ้าช่วงที่มีป้ายในไฟล์ถูกแก้ด้วยมือ (ไม่ตรงกับ `sa-spec`) เว็บจะเตือนตอนเปิด และถามก่อนเขียนทับตอน Save
- ไฟล์ที่สร้างหน้าตาแบบเดียวกับไฟล์ที่เขียนเอง (`GetLogicalNames / GetInputParameters / GetOutputParameters / Draw`) ส่วนที่วาดอยู่ใน class `SaDrawing_<ชื่อ class>` ระหว่างป้าย
  ```
  // ===== SA-DRAWING BEGIN (สร้างโดย SA Drawing Studio — แก้ด้วยการวาดในเว็บ อย่าแก้ช่วงนี้ด้วยมือ) =====
  // sa-spec: {...สิ่งที่วาดทั้งหมด เป็น JSON บรรทัดเดียว...}
  internal static class SaDrawing_LeveeCrest { ... }
  // ===== SA-DRAWING END =====
  ```
  และบรรทัดเรียก 3 บรรทัดที่มีป้าย `// SA-DRAWING TARGET` / `PARAM` / `CALL` ในเมธอดของ class หลัก
  มีคอมเมนต์ภาษาไทยบอกว่าบรรทัดไหนมาจากจุดไหน (`// P4 ลาดจนชนดิน`) · ตรวจขอบเขต parameter แล้วใช้ค่าขอบ + warning · Layout mode / ไม่มี surface วาดแบบไม่มีดิน ไม่ throw
- โค้ดที่สร้างใช้เฉพาะ Civil 3D API ที่ไฟล์ของคุณใช้อยู่แล้ว และตรวจชื่อกับ API Reference 2027 แล้ว — ยังควรลอง build / ใช้ใน Civil 3D จริงอีกครั้ง
- **Import ไฟล์ที่สร้างจากเว็บ** → เว็บอ่านส่วนที่วาดกลับจาก `sa-spec` ให้ เข้า Edit แล้ววาดต่อได้เลย
- ตัวที่ยังไม่มีไฟล์: ✎ แก้โค้ด / "ดูโค้ดที่สร้าง" เปิดแถบโค้ดแบบอ่านอย่างเดียว เปลี่ยนตามการวาด
- ชื่อ parameter ห้ามซ้ำกับชื่อที่โค้ดใช้เอง (เช่น `F`, `cs`, `P1`, คำสงวนของ C#) — เว็บเตือนตอนตั้งชื่อ

## เปิดไฟล์ .cs (Import)

**ไฟล์ ▾ → Import .cs** (หรือคลิกขวาที่ assembly) แล้วเลือก:
- **ไฟล์ในโฟลเดอร์นี้** — วางไฟล์ไว้ในโฟลเดอร์นี้ เว็บอ่านเฉพาะไฟล์ .cs ชั้นบนสุด (ไม่อ่านโฟลเดอร์ย่อย)
  อยากใช้โฟลเดอร์อื่น: แก้ `"SubassemblyFolder"` ใน `SA.Web\appsettings.json`
- **เปิดจากเครื่อง…** — ไฟล์จากที่ไหนก็ได้ ถ้าใช้ Chrome หรือ Edge เว็บจะติดตามการ Save ไฟล์นั้นให้ด้วย
  (หลังรีเฟรชหน้าเว็บ ตัวนั้นใช้โค้ดที่จำไว้ ต้อง Import ใหม่ถ้าจะให้ติดตามไฟล์ต่อ)
- **+ สร้างไฟล์ใหม่จาก template** — สร้าง `.cs` ใหม่ในโฟลเดอร์ (สันกว้าง Width + ลาดถม/ตัดชน Target Surface) แล้วเปิดแถบโค้ดให้

ตัวแรกของ assembly จะเกาะแกนให้เอง (เหมือนโหมดไฟล์เดียวเดิม) ตัวต่อไปลอยอยู่เหนือแกน

ไฟล์ .cs ต้องมี public class ที่มีเมธอด `public void Draw()` (แบบเดียวกับที่ .atc เรียก)
ถ้ามีหลาย class ในไฟล์เดียว จะมี dropdown ให้เลือก class ใน Properties ของ subassembly นั้น

## แก้โค้ดในเว็บ

- **✎ แก้โค้ด** (หรือ `Ctrl+E`) เปิด/ปิดแถบโค้ดของ subassembly ที่เลือกอยู่ ลากขอบขวาของแถบเพื่อปรับความกว้าง
  เลือกตัวอื่นในต้นไม้ แถบโค้ดจะเปลี่ยนไปเปิดไฟล์ของตัวนั้น
- พิมพ์แล้วรูปวาดใหม่เองหลังหยุดพิมพ์ ~0.4 วินาที (ใช้โค้ดในแถบ แม้ยังไม่บันทึก)
- **บันทึกลงไฟล์อัตโนมัติ** หลังหยุดพิมพ์ ~1 วินาที (`Ctrl+S` = บันทึกทันที) คงรูปแบบไฟล์เดิมไว้ (BOM, CRLF/LF)
- error จากคอมไพเลอร์ขึ้นเป็นเส้นหยักในโค้ด · คลิกบรรทัดในกรอบแดงเพื่อกระโดดไปที่โค้ดตรงนั้น
- **แก้ไฟล์เดียวกันใน Antigravity พร้อมกันได้**
  - ในเว็บไม่มีอะไรค้างบันทึก → เว็บโหลดฉบับใหม่จากไฟล์ให้เอง (Ctrl+Z ย้อนกลับได้)
  - ในเว็บมีส่วนที่ยังไม่บันทึก → เว็บหยุดบันทึกอัตโนมัติ แล้วให้เลือก "เก็บฉบับในเว็บ" หรือ "ใช้ฉบับในไฟล์" (ไม่เขียนทับเงียบๆ)
- ไฟล์ที่ **เปิดจากเครื่อง…**: Chrome/Edge บันทึกกลับไฟล์เดิมได้ (เบราว์เซอร์จะขอสิทธิ์ครั้งแรก)
  เบราว์เซอร์อื่นแก้ได้ในเว็บแต่ต้องกด **ดาวน์โหลด** เอง
- ตัวแก้โค้ดคือ Monaco (ตัวเดียวกับ VS Code) โหลดจากอินเทอร์เน็ต (cdn.jsdelivr.net)
  ถ้าโหลดไม่ได้จะใช้ช่องข้อความธรรมดาแทน ยังบันทึกและวาดรูปได้ปกติ แต่ไม่มีสีโค้ด/เส้นหยัก

## โค้ดค้าง (loop / recursion ไม่จบ)

ตอนคอมไพล์ เว็บแทรกจุดตรวจไว้ต้น loop และต้น method ทุกตัว (ในหน่วยความจำเท่านั้น ไฟล์จริงไม่ถูกแก้ และเลขบรรทัดไม่เลื่อน)

- รันเกิน **3 วินาที** → หยุดจริง และแจ้ง Timeout พร้อมบรรทัดที่ค้าง (แม้โค้ดจะ `catch (Exception)` ไว้เองก็ตาม)
- recursion ลึกผิดปกติ → หยุดก่อน stack ล้น (เดิมทำให้เว็บล่มทั้งตัว)
- ค้างในจุดที่ไม่มี loop เช่น `Thread.Sleep` → เลิกรอที่ 6 วินาที (ตัวที่ค้างยังวิ่งอยู่เบื้องหลัง ถ้าเว็บช้าให้ปิดแล้วเปิด run-viewer ใหม่)

**ความปลอดภัย:** เว็บนี้คอมไพล์และรันโค้ด C# บนเครื่องนี้จริง และเขียนไฟล์ในโฟลเดอร์ได้
เปิดให้เข้าได้เฉพาะ `localhost` (ค่าใน `SA.Web/Properties/launchSettings.json`) อย่าเปลี่ยนให้เครื่องอื่นในเครือข่ายเข้าถึง

## Assembly (ประกอบหลาย subassembly)

workspace มีได้หลาย assembly (คลิกขวาที่ Workspace → **+ Assembly ใหม่**) แต่ละตัวมีแกน ⊞ ของตัวเอง ใช้เส้น surface ร่วมกัน

1. Import .cs เข้า assembly → ตัวแรกเกาะแกนเอง ตัวต่อไปลอยอยู่เหนือแกน (◇ เส้นประสีส้ม)
2. ลากตัวมัน (หรือจุด ◇ origin) ไปปล่อยใกล้ **แกน assembly** (⊞ เส้นประสีชมพู) หรือใกล้จุดของ subassembly ตัวอื่น
   (หรือเลือกแล้วกด `M` คลิกจุดฐาน → คลิกปลายทางบนแกน / จุด — ดูหัวข้อ **Move / Copy / Paste**)
   - ระหว่างลากจะเห็นวงกลมรอบจุดที่เกาะได้ ปล่อยใกล้จุดไหน (ไม่เกิน ~14 px) จะเกาะจุดนั้น
   - ปล่อยห่างทุกจุด = ยังไม่เกาะ (ลอยอยู่) · ลากตัวที่เกาะอยู่ออกมา = ปลด
   - ปล่อยที่แกนหรือจุดของ **assembly อื่น** = ย้ายไป assembly นั้น (พร้อมตัวที่เกาะอยู่กับมัน)
3. แกน assembly ลากไปวางตรงไหนก็ได้ ตัวที่เกาะอยู่จะตามไปทั้งชุด · ระดับแกนแก้เป็นตัวเลขได้ใน Properties ของ assembly

- **เกาะด้วย point code** (เช่น `TrapTopOutside`) จุดเลื่อนเมื่อเส้น surface เปลี่ยนก็ยังเกาะถูกจุด
  ถ้าจุดนั้นไม่มี code จะเกาะด้วยลำดับจุดแทน (ขึ้นในต้นไม้ว่า "ไม่มี code" เพราะลำดับอาจเลื่อนได้)
  ถ้าตัวแม่ไม่มี code นั้นแล้ว ต้นไม้จะขึ้น ⚠ และใช้ตำแหน่งล่าสุดแทน
- คลิกตัวไหนในต้นไม้หรือบนรูป → Properties / แถบผลลัพธ์ (Messages / Log / Points) เป็นของตัวนั้น
  และแถบโค้ด (✎ แก้โค้ด) เปิดไฟล์ของตัวนั้น แก้โค้ดแล้วทุกตัวที่ใช้ไฟล์เดียวกันวาดใหม่ทันที
- แต่ละตัวมี parameter ของตัวเอง (ไฟล์เดียวกันใส่ได้หลายตัว เช่น ซ้าย/ขวา) · **Rename** เปลี่ยนแค่ชื่อที่แสดง ไฟล์ไม่เปลี่ยนชื่อ
- **Mirror** สร้างสำเนาฝั่งตรงข้าม (สลับ parameter `Side`) พร้อมตัวที่เกาะอยู่กับมันทั้งหมด
- **เอาออกจาก assembly** (ไฟล์ .cs ไม่ถูกลบ) ตัวที่เกาะอยู่กับมันจะลอยอยู่ที่เดิม
- **ไฟล์ ▾ → Save project / Save project as…** เก็บเป็น `ชื่อ.assembly.json` ในโฟลเดอร์นี้ (parameter, จุดเกาะ, แกน, เส้น surface, ค่าแถบล่าง)
  **Open project…** เปิดกลับ (แทนที่ workspace) · ไฟล์จากโหมด Assembly เดิมเปิดได้
  workspace ที่มี assembly เดียวบันทึกเป็นรูปแบบเดิม (เว็บรุ่นก่อนเปิดได้) · หลาย assembly บันทึกเป็นรูปแบบใหม่ (`version: 2`)
- Points ในแถบผลลัพธ์และ Properties แสดง **เทียบ origin ของตัวที่เลือก** (ค่าเดียวกับที่โค้ดส่งให้ `Points.Add`)
  ส่วน tooltip บนรูปและแถบล่างแสดง offset จากแกน assembly และระดับจริง

ในตัวจำลอง แต่ละตัวได้ `CurrentOffset/CurrentElevation` = ตำแหน่งจริงของจุดเกาะ,
`CurrentSubassemblyOffset/Elevation` = ตำแหน่งจุดเกาะเทียบแกน assembly (ตาม API Reference)

ยังไม่รองรับ: marked point (`ParamsPoint`), ส่ง output parameter ของตัวหนึ่งไปเป็น input ของอีกตัว, offset/elevation target

## เว็บทำอะไรกับไฟล์ .cs

เรียกตามลำดับเดียวกับ Civil 3D:

1. `GetLogicalNames()` → target ที่ประกาศไว้ (Target Surface ฯลฯ) จะแสดงใน Properties ของ subassembly
2. `GetInputParameters()` → สร้างช่องกรอก parameter ให้อัตโนมัติ (long / double / string / bool)
   ช่องที่แก้จากค่า default จะเป็นสีฟ้า; parameter ชื่อ `Side` จะเป็น dropdown Right/Left
3. นำค่าที่กรอก + surface ที่ลากในเว็บไปใส่ แล้วเรียก `Draw()`
4. วาด points / links / shapes พร้อม code และแสดงสิ่งที่ `RecordError` บันทึกไว้

**Debug ได้ด้วย `Console.WriteLine(...)`**: ข้อความจะขึ้นในช่อง Log ของเว็บ
(ใน Civil 3D จะไม่แสดงอะไร จึงทิ้งไว้ในโค้ดได้)

ถ้าโค้ดโยน exception ออกมาโดยไม่ได้ catch เว็บจะแสดงกรอบแดงพร้อมเลขบรรทัด

## เส้น surface

- ลากจุด = ขึ้น-ลง · Shift+ลาก = เลื่อนแนวราบด้วย
- ลากที่ตัวเส้น = เลื่อน surface ทั้งเส้น (แบบ SAC)
- ดับเบิลคลิกที่เส้น หรือกด `A` แล้วคลิกบนเส้น = แทรกจุด
- คลิกขวาที่จุด หรือ `Delete` = ลบจุด · `F` = Fit · ล้อเมาส์ = zoom · ปุ่มกลางเมาส์ลาก / `Space` + ลาก = pan (ลากพื้นหลังด้วยปุ่มซ้าย = คลุมเลือก)
- ทุกการแก้เส้น surface ย้อนได้ด้วย `Ctrl+Z` (ลากต่อเนื่อง = ก้อนเดียว)
- คลิก **Surface: EG** ในต้นไม้ (หรือคลิกที่เส้น) เพื่อดูปุ่ม Add point / ลบจุด / รีเซ็ต และตัวเลือกใน Properties
- ติ๊ก "กำหนด surface ของเว็บให้ Target Surface" ออก = จำลองกรณีไม่ได้กำหนด target
- "ต่อปลายเส้นออกไปแนวราบ" (เปิดไว้เป็นค่าเริ่มต้น) = surface กว้างไม่จำกัด เหมือน TIN จริงที่ใหญ่กว่า section
  ปิดเมื่ออยากทดสอบกรณีโค้ดถามระดับนอกขอบเขต surface (จะได้ PointNotOnEntityException)
- Mode = Layout จำลอง Layout mode ของ Civil 3D (Properties ของ Workspace)

## ระบบพิกัดจำลอง

- จุดที่โค้ดสร้างด้วย `Points.Add(offset, elevation, ...)` เป็นค่าเทียบ origin (แบบเดียวกับ Civil 3D)
- ส่วน `IntersectSurface`, `SampleSection`, `FindElevationAtXY`, `CurrentElevation` ใช้ค่าจริง (absolute)
  โดยแกน assembly อยู่ที่ offset 0 และระดับจริง = **Datum** + ความสูงของแกนบนจอ (Datum ค่าเริ่มต้น 100 แก้ได้ใน Properties ของ Workspace)
  ถ้าโค้ดลืมแปลงระหว่างค่าจริงกับค่าเทียบ origin รูปจะเพี้ยนไป ~100 m ซึ่งช่วยจับ bug ได้
- alignment จำลองเป็นเส้นตรง: `PointLocation(station, offset)` ให้ X = offset, Y = station

## ตัวจำลอง Civil 3D API (SA.Civil3DShim)

มีเฉพาะส่วนที่ subassembly ใช้กันบ่อย:

| namespace | สิ่งที่มี |
|---|---|
| `Autodesk.Civil.Runtime` | `CorridorState` (ParamsLong/Double/String/Bool/Surface/Alignment/Profile, Points, Links, Shapes, Mode, Current*, RecordError, IntersectSurface, SampleSection), `Point`, `Link`, `Shape`, `CodeCollection`, `PointInMem`, `IPoint`, `SampledSectionLink` |
| `Autodesk.Civil` | `CorridorMode`, `CorridorError`, `CorridorErrorLevel`, `ParamLogicalNameType`, `PointNotOnEntityException` |
| `Autodesk.Civil.ApplicationServices` | `CivilApplication.ActiveDocument.CorridorState` |
| `Autodesk.Civil.DatabaseServices` | `Surface`/`TinSurface.FindElevationAtXY`, `Alignment.PointLocation/StationOffset` |
| `Autodesk.AutoCAD.DatabaseServices` | `ObjectId`, `OpenMode`, `Transaction`, `TransactionManager.GetObject`, `HostApplicationServices.WorkingDatabase` |
| `Autodesk.AutoCAD.Geometry` | `Point2d`, `Point3d` |

ถ้าไฟล์ .cs เรียก API ที่ยังไม่มี เว็บจะขึ้น compile error เช่น
`'CorridorState' does not contain a definition for 'XYZ'` → เพิ่มเข้าไปในไฟล์ของ `SA.Civil3DShim`
(dotnet watch จะ restart ให้เอง) หรือส่งชื่อฟังก์ชันให้ Claude เพิ่ม

ยังไม่รองรับ: offset/elevation target, หลาย surface พร้อมกัน, superelevation, profile จริง

## ข้อควรรู้

- ตัวจำลองเขียนขึ้นให้ชื่อและการทำงานใกล้เคียงของจริงที่สุด แต่**ไม่ใช่ Civil 3D จริง**
  เช่น ถ้า `IntersectSurface` หาจุดตัดไม่เจอ ตัวจำลองจะโยน exception (ของจริงอาจทำต่างออกไป)
  ผลสุดท้ายยังควรเช็คใน Civil 3D อีกครั้ง
- กรณีที่บันทึกไว้ใน Scenarios (แถบซ้าย) เก็บอยู่ในเบราว์เซอร์ สำรองเป็นไฟล์ JSON ได้ที่ ไฟล์ ▾ → Export scenarios · กรณีที่บันทึกจากเว็บรุ่นก่อนยังโหลดได้
- โฟลเดอร์ `SA.Core`, `SA.Civil3D` มาจากแนวทางแรก (แยก logic ของ Trapezoid ออกมา) เว็บไม่ได้ใช้แล้ว
  (`SA.Tests` ยังใช้ทดสอบเว็บ — อย่าลบ)
