## 1. Parameter ชนิด Slope (1:x)

**ปัญหา:** ไฟล์ของผู้ใช้เก็บ slope แบบ "1:x" เป็นตัวเลข x (`SideSlope = 1.5` = 1:1.5 ดิ่ง:ราบ แล้วใช้ `Depth * SideSlope`) แต่ช่อง slope ในเว็บ (Slope to Surface,
Daylight Cut/Fill, Extend to Surface ฯลฯ) ต้องการ "ดิ่งต่อราบ" มีเครื่องหมาย (`-1/1.5` = −0.667) → ผู้ใช้ตั้ง default ลำบาก และต้องรู้ทริค `-1/SideSlope` เอง

**ที่ต้องทำ:**
- ตาราง Parameter มีช่อง **ชนิดค่า** (แยกจากชนิดข้อมูล double / long): `Number` (เดิม) / **`Slope (1:x)`** / `Length (m)` / `Percent (%)` — เสนอรายการใน M0
- ชนิด `Slope (1:x)`: ช่อง default / min / max **พิมพ์ `1:1.5` ได้** (หรือ `1.5`) และแสดงเป็น `1:1.5` ทุกที่ (ตาราง, Properties, ข้อความเตือน "SideSlope = 1:0.5 < 1:1 ใช้ 1:1 แทน")
  — ค่าที่เก็บ / ค่าที่ใช้ในนิพจน์ = x (1.5) เหมือนไฟล์ของผู้ใช้ และเหมือน C# ที่สร้าง (`double SideSlope = 1.5`)
- **ช่อง slope ทุกช่องของเครื่องมือ** รับได้ทั้ง (ก) ค่าเดิมแบบดิ่งต่อราบ (ข) `1:1.5` (ค) ชื่อ parameter ชนิด Slope เช่น `SideSlope` → เว็บแปลงเป็น `-1/SideSlope` ให้เอง
  โดยทิศ **ขึ้น / ลง** เป็นปุ่ม ↗ ↘ แยกจากตัวเลข (ไม่ต้องใส่เครื่องหมายเอง) — ออกแบบให้ของเก่า (spec ที่มี `-1/SideSlope` อยู่แล้ว) เปิดได้และผลเหมือนเดิม
- ชนิด `Length (m)`: ข้อความเตือนมีหน่วย m · `Number`: ไม่มีหน่วย (ตอบคำถามข้อ 7 ของรอบ 4c ไปในตัว)
- C# ที่สร้าง: นิพจน์ slope ออกมาอ่านง่ายเหมือนเขียนเอง เช่น `-1.0 / SideSlope` · ข้อความเตือนตรงกับในเว็บ
- test: แปลง `1:1.5` ↔ 1.5, ช่อง slope ทั้ง 3 แบบให้ผล JS = C# (Right / Left), spec เก่าไม่เปลี่ยนผล, ขอบเขต min ของชนิด Slope

## 2. ปุ่มปิด (×) ของหน้าต่างเครื่องมือกดไม่ได้

**ปัญหา:** ผู้ใช้กดปุ่มปิดในหน้าต่าง / แผงของเครื่องมือต่างๆ แล้วไม่ปิด ต้องกด `Esc` ทุกครั้ง

**ที่ต้องทำ:**
- **reproduce ก่อน**: ไล่เปิดทุกหน้าต่าง / แผงที่มีปุ่มปิดหรือปุ่ม "ยกเลิก" — หน้าต่างของ Daylight Cut/Fill, Extend to Surface, Clipped Surface Link, Intersect, Offset, Array,
  Regular Polygon, Arc, Fillet, ตาราง Parameter, ลบ decision, dialog กลาง (`#modal` / `#dlg-x` / `closeDialog` ใน `ui.js`), banner ของคำสั่ง, เมนู ฯลฯ
  แล้วจดว่าอันไหนกดไม่ได้และเพราะอะไร (เช่น handler ไม่ผูก, ปุ่มถูกสร้างใหม่ทุก render แล้ว handler หาย, pointer capture / overlay บังปุ่ม, ปิดหน้าต่างแต่เครื่องมือยังค้าง)
- แก้ให้ **ปุ่มปิด = ผลเดียวกับ `Esc`** ทุกที่ (ปิดหน้าต่าง + ยกเลิกเครื่องมือ / คำสั่งที่ค้าง + ไม่แก้ spec) — ทำเป็นฟังก์ชันเดียวใช้ร่วมกัน
- คลิกพื้นหลังมืดของ dialog = ปิดด้วย (ยกเว้นหน้าต่างที่กำลังพิมพ์ค่าค้างอยู่ ให้เสนอใน M0)
- รายงานผู้ใช้เป็นตาราง: หน้าต่าง → ก่อนแก้ / หลังแก้
